# 메이플 연금술 수익 계산기

공개 사이트: https://happyleeyi.github.io/maple-alchemy-calculator/

재획 타이머: https://happyleeyi.github.io/maple-alchemy-calculator/timer.html

## 재획 타이머

30분·1시간·2시간 프리셋, 직접 시간 설정, 시작·일시정지·초기화·5분 연장, 중간 알림, 종료 소리, 선택적 브라우저 알림, 전체 화면을 지원합니다. 실행 중 새로고침해도 종료 예정 시각을 기준으로 남은 시간을 복원합니다.

페이지를 닫으면 알림이 울리지 않습니다. 브라우저가 백그라운드 실행을 제한하거나 기기가 절전 상태이면 알림은 늦어질 수 있습니다. 새로고침 뒤 소리 시험을 눌러 소리를 다시 준비하세요. 브라우저 알림 권한은 사용자가 사용 설정을 누를 때만 요청합니다.

타이머는 `timer.html`, `timer.css`, `timer.js`, `timer-core.mjs`를 같은 폴더에 배포합니다. 계산 테스트: `node --test tests/timer.test.mjs`.

## 비약 수익 계산기

재료 매입가와 완제품 판매가를 입력하면 15종 비약의 이틀 예상 순이익을 비교합니다.

- 수수료 기본 3%, 하루 기본 피로도 500
- 회복제 하루 5개 사용 시 피로도 +350, 이틀간 10개 매입비 차감
- 이전 단계 물약은 직접 제작하지 않고 매입
- 24시간·영구·1회 소모 레시피 및 보유 여부 반영
- 재료 수량·제작 피로도·완성 수량 수정, 브라우저 자동 저장, CSV 내보내기

설치나 ChatGPT 계정이 필요 없는 단일 HTML 계산기입니다. `index.html`을 정적 웹호스팅에 올리면 됩니다.

초기 단가는 2026-10-15 확인한 예시입니다. 실시간 시세를 가져오지 않습니다. 수익은 입력한 단가로 재료를 전부 매입하고 생산량을 모두 판매하는 조건입니다. 소형 고농축 경험 축적의 비약 피로도 5는 추정값이므로 게임 제작 화면 확인 후 수정하세요.

입력값은 현재 브라우저에만 저장합니다. 기존 사이트의 입력값은 새 주소로 자동 이전되지 않습니다.
