# 메이플 연금술 수익 계산기

재료 매입가와 완제품 판매가를 입력하면 15종 비약의 이틀 예상 순이익을 비교합니다.

- 수수료 기본 3%, 하루 기본 피로도 500
- 회복제 하루 5개 사용 시 피로도 +350, 이틀간 10개 매입비 차감
- 이전 단계 물약은 직접 제작하지 않고 매입
- 24시간·영구·1회 소모 레시피 및 보유 여부 반영
- 재료 수량·제작 피로도·완성 수량 수정, 브라우저 자동 저장, CSV 내보내기

설치나 ChatGPT 계정이 필요 없는 단일 HTML 계산기입니다. `index.html`을 정적 웹호스팅에 올리면 됩니다.

초기 단가는 2026-10-15 확인한 예시입니다. 실시간 시세를 가져오지 않습니다. 수익은 입력한 단가로 재료를 전부 매입하고 생산량을 모두 판매하는 조건입니다. 소형 고농축 경험 축적의 비약 피로도 5는 추정값이므로 게임 제작 화면 확인 후 수정하세요.

입력값은 현재 브라우저에만 저장합니다. 기존 사이트의 입력값은 새 주소로 자동 이전되지 않습니다.
